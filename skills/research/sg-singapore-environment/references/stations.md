## Notes

- `curl -s -f` (NOT `urllib.request`) to fetch — api-open.data.gov.sg silently returns HTTP 403 with urllib
- Validate station count ≥ 60 after fetch — partial responses return code:0 with fewer stations
- Coordinates are WGS84; use haversine for distance calculations
